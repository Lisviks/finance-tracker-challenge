# Transaction Form

## Goal

Create the form a user will use to enter new income and expense transactions.

## Checklist

- [ ] Add a description field.
- [ ] Add an amount field.
- [ ] Add a simple type control for income or expense.
- [ ] Add a simple category control.
- [ ] Add a date field.
- [ ] Add a submit button.
- [ ] Use labels for every input.
- [ ] Add basic validation where helpful.

## Notes

Keep controls simple and accessible. Custom dropdowns are not required.
