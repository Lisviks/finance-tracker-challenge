# Add Transaction Flow

## Goal

Make the form create new transactions and add them to the app state.

## Checklist

- [ ] Listen for form submission.
- [ ] Keep the user in the app after submission.
- [ ] Read description, amount, type, category, and date.
- [ ] Reject empty descriptions and invalid amounts.
- [ ] Create a transaction with a unique ID.
- [ ] Add the transaction to state.
- [ ] Reset the form after a successful submit.

## Notes

After this card, the new transaction does not need to persist yet. Persistence comes later.
