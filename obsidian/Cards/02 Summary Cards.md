# Summary Cards

## Goal

Build the four summary cards that show balance, income, expenses, and savings.

## Checklist

- [ ] Add one card for total balance.
- [ ] Add one card for income.
- [ ] Add one card for expenses.
- [ ] Add one card for savings.
- [ ] Include a primary value and short supporting note for each card.
- [ ] Add stable identifiers, component names, or structure that can be updated later from app logic.

## Notes

The values can start as placeholders. They will become calculated values later.
