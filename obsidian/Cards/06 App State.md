# App State

## Goal

Define the transaction data shape and create the first version of app state.

## Checklist

- [ ] Decide what fields each transaction needs.
- [ ] Create sample income and expense transactions.
- [ ] Store transactions in one simple collection.
- [ ] Define budget limits in one predictable place.
- [ ] Keep data names consistent with the UI.

## Notes

Avoid splitting state too early. One transaction collection is enough for this app.
