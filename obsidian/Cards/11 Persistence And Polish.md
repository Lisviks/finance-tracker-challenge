# Persistence And Polish

## Goal

Persist transactions and finish the app with manual testing and small UI improvements.

## Checklist

- [ ] Load saved transactions when the app starts.
- [ ] Save transactions after adding a transaction.
- [ ] Save transactions after deleting a transaction.
- [ ] Provide a useful fallback when no saved data exists.
- [ ] Add or verify empty states.
- [ ] Check the interface at small and large screen sizes.
- [ ] Restart or reopen the app and confirm data remains.
- [ ] Review naming, formatting, and user-facing text.

## Notes

This final card is about reliability. Test the app like a user who may enter imperfect data.
