# Conditional Categories

## Goal

Update the category control so it shows categories that match the selected transaction type.

## Checklist

- [ ] Define expense categories.
- [ ] Define income categories.
- [ ] Rebuild category options when type changes.
- [ ] Keep the selected category valid after switching type.
- [ ] Confirm form submission uses the current category value.
- [ ] Confirm the form resets to a sensible default.

## Notes

This is a good UI state practice task because it changes available options based on another input.
