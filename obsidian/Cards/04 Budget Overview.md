# Budget Overview

## Goal

Create the budget panel that shows spending progress for key expense categories.

## Checklist

- [ ] Choose a small set of expense budget categories.
- [ ] Add a label and value area for each budget row.
- [ ] Add a visual progress bar for each category.
- [ ] Make the rows easy to update later from app state.
- [ ] Keep budget limits simple and visible.

## Notes

Only expense categories need budget progress in the first version.
